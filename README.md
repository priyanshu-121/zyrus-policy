# zyrus-policy
Your privacy matters to us. This policy explains what data Zyrus accesses, why it’s needed, and how it’s handled.

## Data We Access
Zyrus may access the following Discord data:

- User Presence Data
- Message Data
- Guild & Guild Member Data

## How This Data Is Used
This data is required to properly provide core bot features such as:

- AntiNuke protection
- Moderation tools
- AutoMod systems
- Logging, automation, and other utility features(You can see the full feature list in the help menu.)

## Data Storage & Retention
Message Data and Guild Member Data may be stored **outside Discord** for **less than 30 days.**
Data is only stored when necessary for bot functionality.
We do not sell, trade, or misuse user data in any form.

## Data Deletion
If you want your data removed:

- You can request deletion immediately via the Support Server
- Or by using the ?zyrus command
- Or creating issue in policy [repository](https://github.com/priyanshu-121/zyrus-policy)

Once requested, the data will be permanently deleted.

## Final Note
Zyrus only accesses data that is essential to deliver a safe, secure, and smooth experience. By using the bot, you agree to this policy.
